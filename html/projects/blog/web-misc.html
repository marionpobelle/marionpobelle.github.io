POMODORO TIMER

June 2026 - 2 days

A small Pomodoro Timer desktop application. It was made using Electron.js as well as Node.js.

Each time for focus, break and long break sessions is customizable and saved for the timer's next use.

In addition to basic buttons (start, pause, reset), a button allows to switch in between each mode (focus, break, long break) and another button allows the user to change the color scheme of the application!

I also made custom minimize and close buttons for the application to allow for more visual customization if needed.

A circle is dynamically animated following the current timer status. When the timer runs out, a notification is displayed on the application to indicate that the session is over and a SFX is played.

TO DO LIST

May 2026 - 2 days

A small To Do List desktop application. It was made using Electron.js as well as Node.js.

The user can add as many tasks as they would like and they are saved for future use.

Each task can be marked as completed or to do. Each task has 4 buttons to: reposition the task above, reposition the task below, edit the task or delete the task.

I used this project to learn how to change application icons.
