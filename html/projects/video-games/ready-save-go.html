OVERVIEW

Ready? Save, Go! is an entry for the Coolmath Game Jam 2026, with the objective to teach players about financial literacy concepts and how to use money wisely.

You just moved out from your parents’ place and you want to learn to become independent. For the upcoming year you must manage your money, and have at least 5000$ in your savings while being as happy as possible to see if you can make it on your own!

My duties included:

  • Develop gameplay features (minigames, random events, scoring system…)
  • UI design and implementation (menus, scoreboard, lobby, HUD…)
  • Asset integration (2D sprites, animations, music and SFX…)
  • Collaborating closely with the team to ensure the development follows the design and the game can be easily fine-tuned and balanced
  • Maintain a feature list with regular updates so that everyone can track progress
  • And more!

MINIGAMES & RANDOM EVENTS

A minigame is created from a Scriptable Object that defines the minigame's information (name, associated Unity scene, icon) as well as an enumerator for consistent tracking. This allow the application to chose a minigame from a list of enumerator values and to then load the right information and game scene.

Each random event is defined by a Scriptable Object that contains the name of the event, its description, a tooltip text that explains how the outcome of the random event can impact one's financial situation as well as a list of options to pick from. These options themselves are also Scriptable Objects that contains the option's name, money and happiness modifiers as well as the type of impact (immediate if the money and happiness are changed immediately, randomized if the modifier's values can be inversed or delayed if the event's result depends on certain conditions).

GAMEPLAY

Each game is made of 12 loops (that represent a full year) containing a minigame as well as a random event. When a loop is loaded, one random event is selected from a list of all available random events, and two minigames are randomly selected so that the player can choose which one they want to play.

The lobby menu (where random events are played and minigames selected) allows the player to track their current money, happiness and score. It also displays additional information, such as monthly salary, expenses as well as the year's timeline.

For ease of use and to accommodate browser support, each minigame uses mouse only controls.
