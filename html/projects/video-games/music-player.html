Music Player

Platform: PC
Duration: 3 months
Team size: 1
Role: Programmer

Find on Itch.io

OVERVIEW

A Music Player made with Electron.js and Node.js, using HTML, CSS and JavaScript! The application goes into the user's Music folder, gather any .mp3 or .wav file it can find and plays them! There is a mini version as well as a desktop version that has more features.

My duties included:

  • Developping the systems (gathering data, progress bar, play/pause/next/previous logic, queue, playlists...)
  • Implementing the UI using CSS
  • Performance control and optimization
  • And more!

FEATURES - MINI PLAYER

There are 3 buttons at the top of the application: to the left, a button to change the color scheme of the display, in the middle, a volume slider to adjust the music volume (saved in between application uses) and on the right, custom minimize and close buttons.

At the bottom, there are buttons that allow the user to switch between repeat, repeat-one and shuffle mode, a progress bar that the player can use to go back or forward in the current audio, previous and next song buttons, a play/pause button as well as a button to pull out the track list.

Each song in the music list is clickable in order to change the playing track!

FEATURES - DESKTOP PLAYER

RIGHT SIDE - PLAYER

There are 3 buttons at the top of the application: to the left, a button to change the color scheme of the display, in the middle, a volume slider to adjust the music volume (saved in between application uses) and on the right, custom minimize and close buttons.

At the bottom, there are buttons that allow the user to switch between repeat, repeat-one and shuffle mode, a progress bar that the player can use to go back or forward in the current audio, previous and next song buttons, a play/pause button as well as a button to pull out the queue list.

MIDDLE SIDE - MUSIC LIST

You can access all of the song from the current playlist in the music list in the middle. Each song in the music list is clickable in order to change the playing track!

There is a search bar allowing you to search for specific songs or artists.

The hearts on the left side of each song in the list represents the songs that are located in a folder named "Favorite", "Favorites", "favorites", "favorites", "Favori", "favori", "Favoris" or "favoris".

Right clicking a song in the list lets the user add it to the queue. The queue resets when changing playlist.

LEFT SIDE - PLAYLISTS

The left side displays all of the available playlists. Clicking a playlist sets it as current playlist and sets up the first song of the playlist as the currently played song. To make playlists, make folders in the Music folder. The name of the playlist will be the name of the folder and the playlist will contain the songs that are in that folder.

There is a search bar allowing you to search for specific playlists.

METADATA

Using Electron.js and Node.js, the music player goes into the Music directory of the user's computer and look at all the files. It skips any file that isn't a .mp3 or a .wav. The desktop version of the music player will look for folders to make playlists from as well.

Then looking at the files, it will fill up an array with each song's information: name, artist, cover art, and path to the audio file. The desktop version will also save the name of the folder the song is stored in to know which playlist it belongs to.

For the name of the song, the application takes the name of the file. For the artist and the cover art, I used the jsmediatags library to be able to get these elements from the file's metadata.
