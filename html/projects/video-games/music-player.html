Music Player

Platform: PC
Duration: 7 days
Team size: 1
Role: Programmer

[COMING SOON] Find on Itch.io

OVERVIEW

A small Music Player made with Electron.js and Node.js! The application goes into the user's Music folder, gather any .mp3 or .wav file it can find and plays them!

My duties included:

  • Developping the systems (gathering data, progress bar, play/pause/next/previous logic...)
  • Implementing the UI using CSS
  • Performance control and optimization
  • And more!

I intend on continuing to work on this project more to make a bigger version of the application that would include playlist integration, queueing songs as well as keyboard shortcuts to play, pause and go to the previous or the next song.

FEATURES

There are 3 buttons at the top of the application: to the left, a button to change the color scheme of the display, in the middle, a volume slider to adjust the music volume (saved in between application uses) and on the right, custom minimize and close buttons.

At the bottom, there are buttons that allow the user to switch between repeat, repeat-one and shuffle mode, a progress bar that the player can use to go back or forward in the current audio, previous and next song buttons, a play/pause button as well as a button to pull out the track list.

Each song in the music list is clickable in order to change the playing track!

METADATA

Using Electron.js and Node.js, the music player goes into the Music directory of the user's computer and look at all the files. It skips any file that isn't a .mp3 or a .wav.

Then looking at the files, it will fill up an array with each song's information: name, artist, cover art, and path to the audio file.

For the name of the song, the application takes the name of the file. For the artist and the cover art, I used the jsmediatags library to be able to get these elements from the file's metadata.
